เชื่อมฐานข้อมูล Saint Theresa กับ Drive

สถานะ: เตรียมตัวเชื่อมต่อแล้ว ต้องเปิดใช้ Apps Script ด้วยบัญชีที่เขียนโฟลเดอร์ ปพ.5 ได้ก่อน จึงจะบันทึกข้อมูลจริงได้

  1. เปิด Google Apps Script สร้างโปรเจกต์ใหม่ชื่อ Saint Theresa Drive ไม่วางทับ Code.gs ของระบบครูเดิม
  2. เปิด โค้ด SaintTheresaDrive.gs คัดลอกทั้งหมดไปแทนโค้ดเริ่มต้น แล้วกดบันทึก
  3. เลือกฟังก์ชัน setupSaintTheresa กด Run และอนุญาต Google Drive ผ่านบัญชีเจ้าของ การตั้งค่านี้ไม่เปลี่ยนสิทธิ์การแชร์โฟลเดอร์
  4. ไปที่ Project Settings → Script Properties คัดลอกค่า ST_ACCESS_KEY เก็บในที่ปลอดภัย รหัสนี้ใช้เชื่อมต่อและถอดรหัสฐานข้อมูล ห้ามส่งรหัสใน GitHub หรือแชต และไม่ควรเปลี่ยนหากยังไม่ได้ย้ายข้อมูลออก
  5. เลือก Deploy → New deployment → Web app ตั้ง Execute as เป็น Me และ Who has access เป็น Anyone แล้วกด Deploy ระบบตรวจรหัสเชื่อมต่อทุกครั้งที่อ่านหรือเขียน หากบัญชีโรงเรียนไม่อนุญาต Anyone ต้องให้ผู้ดูแลบัญชีเปิดทางที่อนุญาตก่อน
  6. คัดลอก Web app URL ที่ลงท้าย /exec กลับ เว็บไซต์ Saint Theresa เลือกใช้งานออฟไลน์ แล้วกด ฐานข้อมูล Drive มุมล่างขวา กรอก URL และ ST_ACCESS_KEY กด ตรวจการเชื่อมต่อ
  7. เครื่องที่มีข้อมูลต้นฉบับ: กด บันทึกลง Drive ครั้งแรก
    เครื่องอื่น: กด โหลดจาก Drive ก่อนเริ่มงาน และกด บันทึกลง Drive ทุกครั้งก่อนจบงาน

วิธีเก็บข้อมูล

ไฟล์เข้ารหัส AES-GCM ชื่อ Saint-Theresa-r000001.json และรุ่นถัดไปจะอยู่ใน โฟลเดอร์ ปพ.5 คงสิทธิ์การแชร์เดิม เก็บข้อมูลของแอปครบทั้งโรงเรียน ห้องเรียน นักเรียน คะแนน เวลาเรียน และการตั้งค่าเอกสาร โดยไม่ส่งการเข้าสู่ระบบ Firebase หรือรหัสเชื่อมต่อ ไฟล์ Google Sheets เดิมไม่ได้ถูกแก้ไข และข้อมูลจาก Sheets เดิมไม่ได้ถูกนำเข้าอัตโนมัติ

การทำงานร่วมกัน

เป็นการกดบันทึกและโหลดทั้งฐานข้อมูล ไม่ใช่การซิงค์สดหรือการรวมข้อมูลอัตโนมัติ เมื่อมีผู้บันทึกรุ่นใหม่ก่อน ระบบจะปฏิเสธการเขียนทับ ให้สำรองงานในเครื่อง โหลดข้อมูลล่าสุด แล้วนำงานที่ค้างมากรอกเพิ่มก่อนบันทึก แนะนำให้สลับกันบันทึกทั้งระบบ

ก่อนโหลดจะถามยืนยันและดาวน์โหลดสำรองข้อมูลเดิม ข้อมูลสำรองนี้เป็นไฟล์ปกติที่ใช้กู้คืนจากเมนูสำรองข้อมูลของแอปได้ หากอินเทอร์เน็ตขัดข้องจะไม่แสดงว่าสำเร็จจนได้รับคำยืนยันจากเซิร์ฟเวอร์

รุ่นย้อนหลังและข้อจำกัด

แต่ละครั้งที่บันทึกจะสร้างไฟล์ใหม่ ไม่มีการลบรุ่นเก่าอัตโนมัติ จำกัดข้อมูลเข้ารหัสประมาณ 11 MB ต่อรุ่น และยังขึ้นกับพื้นที่ localStorage ของเบราว์เซอร์และโควตา Apps Script รหัสเชื่อมต่อจำเฉพาะแท็บที่เปิดอยู่ ส่วน URL จำในเครื่อง

การย้อนรุ่น: สำรองงานในเครื่องก่อน จากนั้นเจ้าของเปลี่ยนค่า Script Property ST_CURRENT_FILE เป็น ID ของไฟล์รุ่นที่ต้องการ แล้วให้ทุกเครื่องโหลดจาก Drive ใหม่ ไม่ควรลบไฟล์รุ่นเก่าหรือแก้ไขเนื้อหาเอง

อ้างอิง: การเผยแพร่ Apps Script และ Content Service
